To facilitate compatibility between Apple and DOS-based systems, the Macintosh operating system created a file called finder.dat whenever it interacted with non-Apple-formatted disks. This file stored crucial metadata about the files on the disk, allowing Apple systems to navigate DOS-formatted disks. Paradoxically, this file, originally intended to enable file interchangeability between systems, now provides us with additional forensic insights. The challenge, however, lies in interpreting the metadata stored in the finder.dat file, as it contains low-level system data not immediately visible through conventional file exploration methods. "
chapter09_fig_03.png,"Unfortunately, we were able to recover only limited data from the Notturno 94 file. However, one interesting date in the metadata, November 6, 1996, appeared significant. This date, two years after Fortini’s death, likely represents the last modification of the file. The issue becomes even more complex when analyzing the other two backup groups. In one of them, the file is located on a damaged floppy disk; in the other backup, the file does not include the letter to Raboni, which is, however, present as a separate file named A Raboni, 24 dic.93. The file includes the string “Lettera non spedita” only after the text termination string (in hexadecimal: 75 00 78). The presence of this string suggests two possible hypotheses: first, a later interpolation through copy and paste; second, the addition of metadata during the saving process, a feature that was possible in early versions of Microsoft Word.
